# Plexus - Un Semplice Framework per Forum in PHP

Plexus è un framework leggero per la creazione di forum online sviluppato in PHP con un design semplice e funzionale. Utilizza un database MySQL per la gestione dei dati e Bootstrap per un'interfaccia utente reattiva.

## Installazione

1.  Clona il repository.
2.  Esegui `composer install` per installare le dipendenze (se presenti).
3.  Configura la connessione al database nel file `config/config.php`
4.  Importa lo schema del database (da creare).
5.  Configura la `BASE_URL` nel file `config/config.php` in base alla tua configurazione del server.
6.  Accedi al forum tramite il tuo browser.
